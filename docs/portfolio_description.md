## 2. LinkedIn / GitHub Project Description
### 📊 Customer Churn Analysis & Retention Intelligence Dashboard (TeleConnect)

**Project Overview:**  
TeleConnect, a subscription-based telecommunications provider, faced rising customer cancellations. As the lead Data Analyst on this project, I performed an end-to-end investigation to uncover churn drivers, quantify annualized revenue at risk, and segment vulnerable customer accounts.

**Tools & Technologies:**  
- **Data Engineering & Cleaning:** Python (Pandas, NumPy)
- **Database & Querying:** PostgreSQL / MySQL (Schema DDL, CTEs, Window Functions, Indexes)
- **Data Visualization:** Python (Matplotlib, Seaborn), Power BI (DAX, Interactive Dashboards)
- **Documentation:** Markdown Data Dictionary, Business Insights Report, Interview Guide

**Key Accomplishments & Insights:**  
- Processed and cleaned a 10,000-record customer dataset, standardizing categoricals, imputing missing values, and engineering derived analytical features.
- Identified contract type and tenure as primary churn drivers—month-to-month subscribers with under 12 months of tenure accounted for over 70% of total revenue at risk.
- Developed a 4-quadrant Customer Value / Risk Segmentation Matrix to isolate high-value at-risk accounts.
- Authored 20 complex SQL queries utilizing CTEs, window functions (`RANK`, `ROW_NUMBER`), and conditional aggregations.
- Designed a 3-page Power BI dashboard specification equipped with DAX metrics (`[Churn Rate %]`, `[Annualized Revenue at Risk]`).
